# Diagramas — Album

Esta pasta concentra diagramas editáveis e exports para o projeto **Album**.

## Convenções sugeridas

| Tipo | Ferramenta sugerida | Nomeação |
|------|----------------------|----------|
| Arquitetura C4 / contexto | draw.io (`.drawio`) ou similar | `contexto-sistema.drawio` |
| Fluxo de usuário | draw.io / Figma | `fluxo-marcacao-figurinha.drawio` |
| ER (banco) | draw.io / dbdiagram.io | `modelo-dados-album.drawio` |

- Preferir formato texto/XML (draw.io XML) para diff em Git.
- Exports PNG/SVG podem ser gerados em CI ou manualmente para README.
